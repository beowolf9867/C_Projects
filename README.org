* Projects Summary

** Craps
- *Path:* =./Craps/=
- *Description:* Game logic and interface for playing or simulating the dice game Craps.

** Flashcard
- *Path:* =./Flashcard/=
- *Description:* Interactive flashcard program designed for creating, editing, and reviewing study decks.

** Notes
- *Path:* =./Notes/=
- *Description:* Organization tools or documents related to project notes and documentation.

** Stack
- *Path:* =./Stack/=
- *Description:* Implementation of the Stack abstract data type (ADT) demonstrating standard operations (LIFO push/pop/peek).

** Text Editor
- *Path:* =./texteditor/=
- *Description:* Simple text editor 

** Word Sorter
- *Path:* =./wordsorter/=
- *Description:* Tool for reading input text, parsing words, and sorting them according to custom rules (alphabetical, frequency, etc.).

** Other
- *Path:* =./other/=
- *Description:* Additional helper scripts and uncategorized projects.
