* Chapter 8: Arrays
** 8.1: One-dimensional arrays
- /aggregate/ variables - store collection of values.
- An *array* is a /data structure/ containing a number of /data values/, all of which have
the same type.
  - These /values/, known as /elements/, can be individually selected by their position within the array.
*** How to declare?
 - To declare an array, we must specify the type of the array’s elements and the number of elements.
#+begin_src C
int a[10];
#+end_src
*** How to read?
 - To read the /elements/ in an array, we use /subscripting/
#+begin_src C
a[0] = 1;
printf("%d\n", a[5]);
++a[i];
#+end_src
*** How to write?
 - To write to the /elements/ in an array, we can
#+begin_src C
int a[10] = {0};
#+end_src
or:
#+begin_src C
int a[15] = {0, 0, 29, 0, 0, 0, 0, 0, 0, 7, 0, 0, 0, 0, 48};
#+end_src
can be rewritten as:
#+begin_src C
int a[15] = {[2] = 29, [9] = 7, [14] = 48};
#+end_src
with the number in brackets a /designator/.
** 8.2: Multi-dimensional arrays
#+begin_src C
int m[5][9]; //five rows and nine columns
#+end_src
- produces a /two-dimensional array/ (a *matrix*). 
*** How are they stored
- C stores arrays in *row-major order*, with row 0, then row 1 all the way to the last row.
